# SshKnownHosts Terraform Module

This module generates `known_hosts`, `ssh`, and `scp` wrapper scripts for accessing Hetzner Cloud servers. 
It helps to avoid issues with OpenSSH host key mismatches and provides convenient local access via generated scripts.

## Features

- Creates a `known_hosts` file using the server's IP and public key.
- Generates wrapper scripts for `ssh` and `scp`.
- Ensures consistent and secure SSH connections.
- Can be reused in any Hetzner Cloud server setup.

## Module Structure

```text
project-root/
└── modules/
    └── ssh_known_hosts/        # Terraform module to generate known_hosts + wrappers
        ├── main.tf             # Module logic – file generation using templates
        ├── variables.tf        # Inputs: loginUserName, server IP, host public key
        └── tpl/                # Template directory for scripts
            ├── ssh.sh          # SSH script template
            └── scp.sh          # SCP script template
```

## Usage

### Add the module to your root module

The following Terraform module is used to generate entries for an SSH `known_hosts` file:

```hcl
module "createSshKnownHosts" {
  source = "../modules/ssh_known_hosts"
  entries = [
    {
      serverName          = hcloud_server.server.name              # The name of the server
      loginUserName       = hcloud_ssh_key.loginUser.name          # The login user to associate with this host
      serverNameOrIp      = hcloud_server.server.ipv4_address      # The IPv4/IPv6 address or hostname of the server
      serverHostPublicKey = tls_private_key.host.public_key_openssh # The server’s public SSH host key
    }
  ]
}
```

Each entry in the `entries` array is transformed into a single line following the format:

```text
${entry.serverNameOrIp} ${entry.serverHostPublicKey}
```

Since `entries` is an array, you can define multiple hosts by simply adding more objects. 
This allows you to flexibly manage SSH known hosts across your infrastructure.

## Outputs

You can optionally define outputs in your root module:

```hcl
output "ssh_command" {
  value = "${path.module}/bin/ssh"
  description = "SSH wrapper command"
}

output "scp_command" {
  value = "${path.module}/bin/scp"
  description = "SCP wrapper command"
}
```
