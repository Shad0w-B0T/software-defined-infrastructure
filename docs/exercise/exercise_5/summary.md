# Summary

- Check if existing SSH keys are available on your system.
- Copy and use your public key for GitLab SSH authentication.
- Add the SSH key to your MI GitLab account under **Preferences → SSH Keys**.
- Use `git clone` with the SSH format to securely access your repositories.
- Verify SSH Git access by running `git pull` and `git push`.
- Understand the importance of key expiration and rotating keys regularly.
