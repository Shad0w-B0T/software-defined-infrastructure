# SSH Access to MI GitLab

This guide explains how to configure SSH-based access to the MI GitLab instance  
[gitlab.mi.hdm-stuttgart.de](https://gitlab.mi.hdm-stuttgart.de), enabling secure and passwordless Git operations like `clone`, `push`, and `pull`.

For more details, see the official documentation:  
[docs.gitlab.com/user/ssh](https://docs.gitlab.com/user/ssh)
