# Step-by-Step

run tf

This will:

    Register an ACME account (staging)

    Create a wildcard certificate for *.g3.sdi.hdm-stuttgart.cloud

    Save the private key and certificate in the /gen/ folder

You have completed this exercise when:

    The wildcard certificate is issued for your zone

    private.pem and certificate.pem are generated

    The challenge is fulfilled via DNS (RFC2136)
