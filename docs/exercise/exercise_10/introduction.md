# Monitor Authentication Logs in Real-Time

This guide walks you through monitoring login and authentication activity on your server or virtual machine (VM) by continuously viewing the `/var/log/auth.log` file.
By following this process, you will be able to observe authentication events, such as successful and failed login attempts, as they happen in real time.

Additionally, you will simulate an SSH login with a partner to generate live log entries and see how these events are recorded on the system.
