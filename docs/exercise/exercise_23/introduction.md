# Deploying HTTPS with Nginx and a Let's Encrypt Certificate

Overview

This guide outlines the process for deploying a web server using Nginx with a TLS certificate generated by Terraform and Let's Encrypt. The certificate enables HTTPS for the following DNS entries:

    g03.sdi.hdm-stuttgart.cloud

    www.g03.sdi.hdm-stuttgart.cloud

    mail.g03.sdi.hdm-stuttgart.cloud

The goal is to validate a certificate setup using a basic HTTPS endpoint and ensure it covers multiple subdomains.
