# 🛠️ Incrementally Creating a Base System with Terraform

Use Terraform to provision a basic Hetzner cloud instance with SSH key access, firewall rules, secure API access via 
file, and an output of server details after deployment.

## Prerequisites

- Hetzner API token (Hetzner Console → Security → API Tokens)
- SSH key pair available (`ssh-keygen -t ed25519`)
- Terraform installed (`terraform -v`)
