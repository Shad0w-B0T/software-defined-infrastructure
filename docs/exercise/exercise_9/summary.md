# Summary

- Installed `plocate` to enable fast, index-based file searches on Linux.
- Created and updated the file index database using `updatedb`.
- Used `locate` to quickly find files by name based on the index.
- Observed that newly created files are not found until the index is updated.
- Learned that deleted files still appear in results until the index is rebuilt.
