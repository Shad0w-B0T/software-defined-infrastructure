# Improve Your Server’s Security

This guide will walk you through the process of securing a basic server setup using Hetzner Cloud. 
You will learn how to:

- create a secure server using only SSH key authentication
- restrict access via a firewall (ICMP + SSH only)
- set up and test a basic web server (NGINX)
- understand the implications of firewalls for HTTP/SSH access

## Prerequisites

To follow this guide, make sure you have:

- A Hetzner account with access to the Hetzner Cloud Console and an active project.
- SSH installed on your local machine (typically preinstalled on Linux/macOS, or available via tools like Git Bash on Windows).
