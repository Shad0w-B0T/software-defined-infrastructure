Summary

- Understand basic firewall configuration using ICMP and TCP rules.
- Know how to test server reachability via `ping`.
- Learn to enable SSH access by opening port 22 in the firewall.
- Perform system updates and reboots for improved security.
- Install and verify a web server (NGINX) locally and remotely.
- Understand how firewall rules affect HTTP accessibility.
- Generate a secure SSH key pair using `ssh-keygen` with strong parameters.
- Follow best practices for protecting private keys and using strong passphrases.

## Prerequisites

- [Understanding SSH Passphrases (SSH.com)](https://www.ssh.com/academy/ssh/passphrase)  
  Learn why SSH key passphrases are important and how to choose a strong one.

- [Introduction to SSH (SSH.com Academy)](https://www.ssh.com/academy/ssh)  
  A beginner-friendly overview of what SSH is and how it works.

- [Public Key Authentication Explained (SSH.com)](https://www.ssh.com/academy/ssh/public-key-authentication)  
  In-depth explanation of how public key authentication works in SSH.
