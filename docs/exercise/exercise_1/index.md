# Server creation

In this task, you will learn how to deploy a virtual cloud server using the **Hetzner Cloud Console**.  
Hetzner is a well-known European cloud provider offering simplicity, performance, and competitive pricing.

By the end of this task, you will have a secure and accessible cloud server ready for further configuration or development use.

1. First, a firewall is needed for further configuration.
2. Then, create the server itself.
3. Finally, reset the root password if necessary.
