# How to Delete a Server

To permanently remove a server from your infrastructure, follow these steps:

1. **Open the server overview** in your hosting dashboard.
2. Locate the server you want to delete.

<ImageWithCaption
  src="/images/exercise_1/server_delete_1.png"
  alt="Server UI"
  :caption="'Location of the delete option in the interface'"
  :number="1"
/>

3. Click the **Delete** button to initiate the removal process.
4. A confirmation dialog will appear.

<ImageWithCaption
  src="/images/exercise_1/server_delete_2.png"
  alt="Server UI"
  :caption="'Confirmation step before deleting the server'"
  :number="2"
/>

::: tip 💡 Keep the IP Address
If you plan to reuse the IP address later, **retain assigned IPs** when deleting a server.  
This can help avoid DNS changes and speed up future setups.
:::

5. Confirm the deletion.

::: warning ⚠️ **Warning**
This action is irreversible and will permanently delete all data on the server.
:::
