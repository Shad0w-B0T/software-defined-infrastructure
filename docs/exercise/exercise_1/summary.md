# Summary

- Understand how to create a server via Hetzner Cloud.
- Know how to access a server via SSH and interpret SSH fingerprint warnings.
- Learn how to access the server via the web GUI.
- Recognize keyboard layout issues and how to fix them (e.g., switching to a German layout).
